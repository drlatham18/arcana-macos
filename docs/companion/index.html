From your PC to your iPhone

  1. On Windows, enable Arena’s Settings → View Account → Detailed Logs (Plugin Support), restart Arena, and keep Arcana running while you play.
  2. After the match, open Arcana’s Match history → Save for iPhone. Transfer that selected file to your phone using your preferred private file service.
  3. Import the file here. In Safari, use Share → Add to Home Screen for an app-like journal.

This companion reads exported reviews. It does not record games played on iOS or connect directly to your PC. There is no automatic sync or cloud backup.
