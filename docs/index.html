Arcana uses a local rules-based engine. It does not send your Arena logs, notes, or match history to an AI service. The app includes its own runtime, so you don’t need to install Python.

There’s no API connection to set up. If you’re looking for a general-purpose AI coach, this version isn’t one: its explanations are limited by the visible game state and the rules it understands.

GET STARTED IN A FEW MINUTES

From download to your first review.

  1. Install Arcana. Open the downloaded disk image and drag Arcana into Applications. A ZIP download is also available.
  2. Open it once. This release is ad-hoc signed, not Apple-notarized. If macOS blocks it and you trust this download, use Apple’s per-app Privacy & Security → Open Anyway flow. Keep system-wide security protections on.
  3. Enable Arena’s logs. In Arena, choose Settings → View Account → Detailed Logs (Plugin Support), then restart Arena. Arcana normally finds the log and card database automatically.
  4. Play, then reflect. Leave background recording on. Review the completed game in Match history. Try Explore demo first if you want to learn the interface.

Use Connection to select the log or database if your Arena installation is elsewhere. Quitting Arcana or pausing the watcher stops recording.

BEFORE YOUR FIRST GAME

A few honest answers.

Can I use it during competitive matches?

Do not use Arcana for assistance during ranked, competitive, tournament, or prize-bearing matches. Live coaching starts off; it is only for permitted noncompetitive practice and resets after a recorded game ends or the app restarts. Background recording for later study works separately. Arcana is not approved or endorsed by Wizards.

How reliable is this release?

Version 1.3 passes 55 automated engine tests and seven native window-placement checks. The actual public package also recorded two completed games during replay of real Arena logs, saving both reviews and timelines without parser errors. Log replay is different from a new live-match test; full live-match acceptance and physical Intel testing are still pending.

Reviews use limited heuristics. They cannot reconstruct missing log information, evaluate every card interaction, or guarantee the best play. See the release checks and limitations.

Is it actually free? Will I need my own API key?

Yes, this edition is free. It uses no paid AI API, and no key or subscription is required. The download contains the working app.

Does it include all of Magic’s official rules?

It includes original study guides and links to official sources. For exact rule-number lookup, download the current Comprehensive Rules text from Wizards, then use Connection → Import rules text. The file is indexed privately on your Mac.

Where can I report a problem or suggest a feature?

Open an issue on GitHub. Include the app version, Mac model, and steps to reproduce. Issues are public: do not upload raw Arena logs, account details, or private notes. If Arcana is useful to you, a GitHub star helps others discover it.
